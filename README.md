## 📦 Local Setup & Development

```bash
# Clone the repository
git clone https://github.com/Badal-kumar98/badal-portfolio-1.git

# Navigate into the project directory
cd badal-portfolio-1

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```
