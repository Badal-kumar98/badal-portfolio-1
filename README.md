## 🛠 Tech Stack
- **Framework**: React 19, TypeScript, Vite
- **Styling**: Tailwind CSS v4
- **Animations & Smooth Scrolling**: GSAP 3 (ScrollTrigger), Lenis
- **Icons**: Lucide React

## 📦 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn / pnpm

### Installation
```bash
# Clone the repository
git clone https://github.com/Badal-kumar98/badal-portfolio.git

# Navigate to project directory
cd badal-portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```
